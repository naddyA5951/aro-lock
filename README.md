# Arolock - Offline Trail & Hike Tracker

A modern, offline-first outdoor GPS trail recording application built with Kotlin and Jetpack Compose.

## Features
- **Offline Trail Canvas**: Visualizes your GPS path, bearing, speed, and waypoints completely offline without requiring any proprietary API keys.
- **Trek Metrics Engine**: Tracks distance, elevation gain/loss, active pace, and calorie expenditure in real-time.
- **Waypoint & Landmark Pinning**: Pin trail hazards, scenic viewpoints, water sources, and camp locations.
- **GPX Export**: Export and view GPX trail logs directly on device.
- **Local Persistence**: Stores treks locally using modern Android Room SQLite database.
